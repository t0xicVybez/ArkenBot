# Bot Announcements

Opt your server in to receive official ArkenBot update announcements — new features, patches, and important notices — delivered directly to a channel of your choice.

## Setup

1. Go to **Dashboard → Announcements** (under Settings in the sidebar)
2. Toggle **Enable announcements** on
3. Select the **Announcement Channel** where posts should be sent
4. The setting saves automatically when you toggle or change the channel

## What Gets Posted

Only staff-crafted announcements from the ArkenBot team are posted. These include:
- New feature releases
- Bug fix notices
- Downtime or maintenance windows
- Important configuration change requirements

## Disabling

Toggle **Enable announcements** off at any time. You can also change the channel at any point without disabling the feature.

## Tips

- Use a dedicated `#bot-updates` or `#arkenbot-news` channel so announcements don't get lost
- Make the channel read-only for members so only the bot can post
