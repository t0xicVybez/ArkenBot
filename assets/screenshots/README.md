# Screenshots

Drop the README's screenshots in this folder using these exact filenames so the
image links resolve without editing the main README:

| Filename | What to capture | Used where |
|---|---|---|
| `dashboard-overview.png` | The main dashboard after selecting a server — module toggles / home view | Hero image under "The Dashboard" |
| `game-servers.png` | A game-server panel showing live status (FiveM/Rust/ARK/etc.) | Side-by-side row |
| `tickets.png` | A ticket panel or the staff portal view | Side-by-side row |

Optional extras you can add (then reference them in the README): `rank-card.png`,
`leveling.png`, `moderation.png`, `alerts.png`.

## Capture tips
- Use a **1440–1600px wide** browser window for crisp results; PNG format.
- Log into the dashboard at https://arkenbot.app (or your local `:3000`), navigate
  to the feature, and screenshot just the content area.
- Blur or use a throwaway test server if any real member names/IDs are visible.
- Keep files reasonably sized (< ~500 KB each) — compress with e.g. TinyPNG if needed.
